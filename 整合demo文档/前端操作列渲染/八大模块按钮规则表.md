# 八大模块按钮规则表

## 一、概述

本文档整理了八大模块在不同状态与不同角色下的按钮显示规则，并归一到统一动作标识。八大模块为：**论文、教材软著、专利软著、讲座报告、奖励、横向项目、纵向项目、成果转化**。所有按钮规则统一接入 `PageRenderServiceImpl` 中对应的 `buildXxxActions()` 方法输出。

## 二、通用按钮规则定义

### 2.1 通用按钮规则（适用于全部八大模块）

| 序号 | 状态条件 | 角色条件 | 权限条件 | 动作Key | 动作文案 | 颜色 | 展示方式 | 排序 |
|------|---------|---------|---------|---------|---------|------|---------|------|

### 2.2 规则说明

- **角色条件说明**：
  - `记录创建者`：当前登录用户ID等于记录的创建者ID（`isOwner()`）
  - `当前审批节点处理人`：当前用户具有该节点审批权限且记录处于对应审批状态
  - `教研室审批人`：当前用户具有教研室审批角色（如 `jys` 角色）
  - `科研处审批人`：当前用户具有科研处审批角色（如 `ky` 角色）

- **状态条件说明**：
  - `草稿`：状态为 `*_DRAFT`
  - `驳回`：状态为 `*_REJECTED*`
  - `审批中`：状态为 `*_AUDIT`
  - `已通过`：状态为 `*_PASSED`

- **权限条件说明**：
  - `有查看权限`：当前用户拥有模块查看权限（如 `system:paper:detail`）
  - `有编辑权限`：当前用户拥有模块编辑权限（如 `system:paper:edit`）
  - `有删除权限`：当前用户拥有模块删除权限（如 `system:paper:remove`）
  - `有审批权限`：当前用户拥有模块审批权限（如 `system:paper:approve`）

## 十一、后端接入实现指引

### 11.1 Service层接入步骤

1. 在 `PageRenderServiceImpl` 中新增模块专属的 `buildXxxActions()` 方法
2. 根据本文档中对应模块的按钮规则表，在方法中实现动作生成逻辑
3. 在 `buildActions()` 方法的 switch 分支中新增模块 case，调用对应的 `buildXxxActions()` 方法
4. 参考 `buildPaperActions()` 方法的实现模式

### 11.2 规则实现示例（论文模块草稿状态）

```java
// 草稿状态：编辑、删除、提交
if (context.isInState(SciPaperA.PAPER_DRAFT)) {
    if (context.isOwner()) {
        if (context.hasPermission("system:paper:edit")) {
            actions.add(createAction(ACTION_EDIT, "编辑", COLOR_PRIMARY, 2));
        }
        if (context.hasPermission("system:paper:remove")) {
            actions.add(createAction(ACTION_REMOVE, "删除", COLOR_DANGER, 3).setDisplayType("link"));
        }
        if (context.hasPermission("system:paper:edit")) {
            actions.add(createAction(ACTION_SUBMIT, "提交", COLOR_PRIMARY, 4));
        }
    }
}
```

### 11.3 规则优先级

按钮规则的生成优先级为：
1. **状态匹配优先**：首先根据当前状态确定可用动作集合
2. **角色过滤其次**：再根据当前用户角色过滤动作
3. **权限校验最后**：最后根据权限过滤最终展示的按钮

### 11.4 模块复用说明

大部分模块（奖励、教材软著、专利软著、讲座报告、成果转化）的按钮规则都直接复用 `buildPaperActions()` 方法，仅权限前缀和状态前缀不同。实现方式如下：

```java
// 奖励模块复用论文按钮规则（仅权限前缀不同）
private List<PageRenderActionItem> buildRewardActions(PageRenderContext context, String state, Object data) {
    // 临时保存原有权限前缀
    String originalPermPrefix = context.getPermPrefix();
    // 设置奖励模块权限前缀
    context.setPermPrefix("system:reward");
    try {
        // 复用论文模块按钮规则
        return buildPaperActions(context, state, data);
    } finally {
        // 恢复原有权限前缀
        context.setPermPrefix(originalPermPrefix);
    }
}
```
