# 八大模块状态映射表

## 一、概述

本文档整理了八大模块各自的状态码与统一展示语义、颜色、文案的映射关系，供 `PageRenderServiceImpl` 中的通用规则引擎使用。八大模块为：**论文、教材软著、专利软著、讲座报告、奖励、横向项目、纵向项目、成果转化**。

### 1.1 通用规则引擎说明

新方案采用**通用规则引擎**，所有模块共用同一套按钮构造逻辑，仅通过模块注册表区分模块编码、流程编码和权限前缀。通用规则引擎基于状态编码后缀（`_DRAFT`/`_JYS_AUDIT`/`_KYC_AUDIT`/`_PASSED`/`_REJECTED`）自动判断按钮显示规则，无需为每个模块单独编写 `buildXxxActions()` 方法。

### 1.2 状态编码命名规范

所有模块的状态编码必须遵循统一后缀规则：

| 后缀 | 通用语义 | 颜色类型 | 示例 |
|------|---------|---------|------|
| `_DRAFT` | 草稿/待提交 | default（灰色） | PAPER_DRAFT, TEXTBOOK_DRAFT |
| `_JYS_AUDIT` | 教研室审批中 | warning（橙色） | PAPER_JYS_AUDIT, TEXTBOOK_JYS_AUDIT |
| `_KYC_AUDIT` | 科研处审批中 | info（青色） | PAPER_KYC_AUDIT, TEXTBOOK_KYC_AUDIT |
| `_PASSED` | 审批通过 | success（绿色） | PAPER_PASSED, TEXTBOOK_PASSED |
| `_REJECTED` | 审批驳回 | danger（红色） | PAPER_REJECTED, TEXTBOOK_REJECTED |

### 10.2 审批状态配置表（sys_approval_state）

每个模块的每个状态需要在 `sys_approval_state` 表中配置一条记录，字段说明：

| 字段 | 说明 | 示例值 |
|------|------|-------|
| state_code | 状态编码 | PAPER_DRAFT |
| state_name | 状态展示名称 | 草稿 |
| process_code | 所属流程编码 | SCI_PAPER_A |
| color_type | 颜色类型 | default |
| sort_order | 排序序号 | 1 |

### 10.3 审批节点配置表（sys_approval_node）

| 字段 | 说明 | 示例值 |
|------|------|-------|
| node_code | 节点编码 | PAPER_JYS_APPROVE |
| node_name | 节点名称 | 教研室审批 |
| process_code | 所属流程编码 | SCI_PAPER_A |
| node_type | 节点类型 | approve/reject/submit |
| sort_order | 排序序号 | 1 |
