# 八大模块状态映射表

## 一、概述

本文档整理了八大模块各自的状态码与统一展示语义、颜色、文案的映射关系，供 `PageRenderServiceImpl` 中各模块的状态映射加载使用。八大模块为：**论文、教材软著、专利软著、讲座报告、奖励、横向项目、纵向项目、成果转化**。

## 二、论文模块（PAPER）

### 2.1 基本信息

| 属性 | 值 |
|------|---|
| 模块名称 | 论文 |
| 模块编码（process_code） | `SCI_PAPER_A` |
| 状态字段 | `state` |
| 领域类 | `SciPaperA` |
| Service类 | `SciPaperAServiceImpl` |

### 2.2 状态映射表

| 状态编码（state） | 状态名称 | 通用语义 | 颜色类型 | 状态文案 |
|------------------|---------|---------|---------|---------|
| PAPER_DRAFT | 草稿 | 草稿 | default | 草稿 |
| PAPER_JYS_AUDIT | 教研室审批 | 审批中 | warning | 教研室审批中 |
| PAPER_KYC_AUDIT | 科研处审批 | 审批中 | info | 科研处审批中 |
| PAPER_PASSED | 审批通过 | 审批通过 | success | 已通过 |
| PAPER_REJECTED | 审批驳回 | 审批驳回 | danger | 已驳回 |

### 2.3 审批节点

| 节点编码 | 节点名称 | 触发状态 |
|---------|---------|---------|
| PAPER_SUBMIT | 论文提交 | PAPER_DRAFT → PAPER_JYS_AUDIT |
| PAPER_JYS_APPROVE | 教研室审批通过 | PAPER_JYS_AUDIT → PAPER_KYC_AUDIT |
| PAPER_JYS_REJECT | 教研室审批驳回 | PAPER_JYS_AUDIT → PAPER_REJECTED |
| PAPER_KYC_APPROVE | 科研处审批通过 | PAPER_KYC_AUDIT → PAPER_PASSED |
| PAPER_KYC_REJECT | 科研处审批驳回 | PAPER_KYC_AUDIT → PAPER_REJECTED |

## 十、数据库配置要求

### 10.1 审批流程配置表（sys_approval_process）

每个模块的申报/结题流程需要在 `sys_approval_process` 表中配置一条记录：

| process_code | process_name | 说明 |
|-------------|-------------|------|
| SCI_PAPER_A | 论文审批 | 论文模块 |
| REWARD | 奖励审批 | 奖励模块 |
| TEXTBOOK | 教材软著审批 | 教材软著模块 |
| PATENT | 专利软著审批 | 专利软著模块 |
| LECTURE | 讲座报告审批 | 讲座报告模块 |
| HORIZONTAL_APPLY | 横向项目申报审批 | 横向项目申报流程 |
| HORIZONTAL_OVER | 横向项目结题审批 | 横向项目结题流程 |
| VERTICAL_APPLY | 纵向项目申报审批 | 纵向项目申报流程 |
| VERTICAL_OVER | 纵向项目结题审批 | 纵向项目结题流程 |
| TEC_TRA | 成果转化审批 | 成果转化模块 |

### 10.2 审批状态配置表（sys_approval_state）

每个模块的每个状态需要在 `sys_approval_state` 表中配置一条记录，字段说明：

| 字段 | 说明 | 示例值 |
|------|------|-------|
| state_code | 状态编码 | PAPER_DRAFT |
| state_name | 状态展示名称 | 草稿 |
| process_code | 所属流程编码 | SCI_PAPER_A |
| color_type | 颜色类型 | default |
| sort_order | 排序序号 | 1 |

### 10.3 审批节点配置表（sys_approval_node）

每个审批节点需要在 `sys_approval_node` 表中配置，字段说明：

| 字段 | 说明 | 示例值 |
|------|------|-------|
| node_code | 节点编码 | PAPER_JYS_APPROVE |
| node_name | 节点名称 | 教研室审批 |
| process_code | 所属流程编码 | SCI_PAPER_A |
| node_type | 节点类型 | approve/reject/submit |
| sort_order | 排序序号 | 1 |
